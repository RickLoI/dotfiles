# ABOUT
An Hyprland centered configuration for Arch-Linux.

Though menat to be paired with [noctalia-shell](https://github.com/noctalia-dev/noctalia) and 
[noctalia-greeter](https://github.com/noctalia-dev/noctalia-greeter), can also be used as a minimal Hyprland setup.

> [!NOTE]
> If used without noctalia-shell, some bindings may not work.

## Requirements
To work properly, at least the following packages are required:
- `hyprland`
- `kitty`
- `fish`
- `zathura` and `zathura-pdf-poppler`
- `ttf-lilex-nerd`
- `wl-clipboard`

## Installation
### Manual
Althogh we stongly advice to use the installation script,
for a manual installation simply clone the repo and move the files to the proper location.

### Automatic 
Clone the repo and run the provided script
